## 存档原则

- 使用分层 Git 提交记录每一阶段的实现和验证变化。
- 不提交模型权重、SMPL/SMPL-X 受许可模型、数据集、实验视频或大体积结果。
- 不提交服务器地址、密码、令牌、私钥或本机连接脚本。
- `results/phase6/absolute_mean_pelvis_v3/` 仅选择性保存冻结协议与小型清单，不保存生成结果。
